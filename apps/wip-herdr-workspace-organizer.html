How to use this page

This is a safe viewer. Every action copies a command instead of changing Herdr directly. Tick tabs, choose a destination workspace, then copy the multi-tab move command. It rebuilds fresh tabs, closes the original tabs, and resumes Codex or Claude sessions only when the real CLI session is available.
