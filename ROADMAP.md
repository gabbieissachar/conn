# Conn roadmap

What Conn has shipped, what comes next, what is already decided, and what still needs the owner. Last updated 2026-11-10, on the Conn fix queue branch (`fm/conn-fix-queue`), after focus sessions and 20-20-20 eye breaks (decisions F1 to F22), the silent Campus session refresh, file links from the reader opening in the Editor view, the Campus agent bridge core (S2) and Campus stars in the Reader row (S1 of the Campus bridge work; and Campus transcripts on the reader's own page, New conversation in Campus, the Campus 403 sign-in fix; the fix queue itself: wrong transcript, asks read state, sidebar, permission prompts; and Campus sending with a queue, Undo all and Now).

Update rule: every Conn change updates this file in the same branch (see "How to keep this current" at the end).

## Short answer

Conn is a working replacement for the Herdr part of the old setup, and also shows ShopBack Campus conversations (read and, behind a switch, write; first live check is N13). It draws the live sidebar and panes of a Herdr session, shows the reader and organizer as web views, edits text files, and has one guarded write (the compose box). It is **observe-only**: it cannot resize a pane, and the compose box has only been tried against the stand-in Herdr. 626 unit tests (the lab-only ones skip unless a lab session is named) pass, and a full fixture `--ui-check` passes in both flag states on the focus session branch rebased onto the file-links and silent-refresh work (343 checks with the Agent view off, 348 with `--agent-view`, none failing in the last run of each; the Watch setups work adds 33 steps, and its full run with the Agent view off passed all 371 steps; on a busy machine (load average 9 to 19) some runs had one or two live-stream or ask-row steps fail, a different step each time, and the next run passed); the live run of the Watch steps was read-only against the real reader. Memory fits the budget (about 1.0 to 1.1 GB for the whole setup against 4.1 GB before). The CPU target passes on Conn's added share (D6). Several things were checked in process only and need a person at a real screen.

**Next three steps, in recommended order:**

1. **Try `main` on a real screen** (N1), and once focus sessions have landed set up Conn Focus and run the 1-minute test (N21). A person runs the short hand-check lists below. They settle the items that no scripted check can see (trackpad scroll, keys typed at the window, text size on the Retina display, pane first draw; and for focus sessions whether the shortcuts really silence other apps, the eye panel over a full-screen app, and a screen share).
2. **One small fix that needs nothing from Herdr** (N2). Stop showing a superseded reader load as "not reachable". Wide panes wait for control mode (W1).
3. **Set up a Herdr lab session, then build control mode** (N4, N5). The lab step is unblocked: a running `default` session now exists beside `esim`. Window-sized panes need a pane resize, which is a write. A lab session is the safe place to test it, and it also settles compose-box questions that are open on real Herdr (N6).

## How to keep this current

- Each Conn change updates this file in the same branch. A change that ships a piece adds a row to Done with its commit ids and removes or edits the Next or Later row it closes. A change that finds new work adds a row with its source.
- Commit ids go in once the commit exists: add them in a follow-up commit on the same branch, or amend before the branch is merged.
- When the owner answers a keyed question, move it to "Decided and deferred" with the answer and its reason, and delete the card.
- Keep "Short answer" true: re-check the next three steps and the test counts at every update.
- Keep it self-contained: cite decision ids, commit ids and report sections, never paths outside this repository.
- Plain language, short sentences, no em dash.
